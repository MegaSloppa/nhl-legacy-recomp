# Legacy Rogue

A career-long roguelite layer for **Be-A-Pro** in nhl-legacy-recomp: buy absurd perks
(critical slapshots that floor opponents, checks that always flatten, a shockwave) with
Hype earned by playing well, while a Notoriety meter makes the otherwise-realistic league
react to how unnaturally dominant you have become.

- Players / the repo owner: start with `docs/user-guide.md`.
- AI agents: start with `AGENTS.md`.
- Design: `docs/design.md`. Status: `docs/current-status.md`.

Off by default. Enable with the environment variable `NHL_ROGUE=1`.
